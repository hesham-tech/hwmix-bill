# إعداد شركتي خطوة بخطوة
آخر تحديث: 23 نوفمبر 2026.

## الرحلة المختصرة
أربع صفحات: نشاطك ومكان البضاعة، تفضيلات العمل، تجهيز المتجر (اختيارية)، ثم النتيجة. لا توجد وحدة بيع عامة للشركة؛ الوحدة يحددها كل منتج.

الصفحة الأولى تعرض الاسم والهاتف والعنوان والبريد واسم المسؤول، والشعار وروابط التواصل عند فتح تفاصيلها. اختيار المخزن لا ينقله من فرعه، وموقعه يفتح في نافذة مستقلة. الصفحة الثانية تعرض تفضيل تحديث تكلفة الشراء وحجم الفاتورة والشعار والعبارة السفلية ومعاينة لا تنشئ فاتورة. الصفحة الثالثة تحفظ مخزن الطلبات والتواصل والتوصيل، ومقترح استلام المستحقات عند الحاجة دون اعتماد ذاتي.

النتيجة تفصل جاهزية العمل الداخلي عن جاهزية البيع بالمتجر. المتطلبات التفصيلية والصفحات المؤجلة تظهر عند طلبها. المتطلبات التشغيلية الحقيقية للوحدات والفواتير والخزائن والعميل النقدي والاشتراك والموافقات لا تُلغى بسبب إخراج حقولها من الدليل.

## الإعدادات الإضافية
في إعدادات الشركة مركز مصنف للشركة والفريق، المنتجات والمخزون، الفواتير والأموال، التواصل والتنبيهات، المتجر، وأماكن العمل. تتوفر اختصارات مماثلة في الشاشات المرتبطة. كل زر يفتح نموذجًا مستقلًا بنفس لغة التصميم، دون تضمين صفحات الإدارة كاملة. القوائم والنماذج تستخدم الخدمات وواجهات العمليات القائمة مع بوابة صلاحيات إضافية.

تفتح نافذة واحدة فقط. عند الانتقال إلى نموذج إضافي تبقى مسودة الدليل في ذاكرة الجلسة وتعود بعد الإغلاق؛ لا تُحفظ المسودة غير المعتمدة في قاعدة البيانات. الحفظ الجزئي لا يمس الحقول المستبعدة. التراجع أو فشل الحفظ لا يغير الصفحة التالية، ويظل التعارض بحاجة إلى تحميل النسخة المحفوظة ومراجعتها. لا يحفظ التخطي التعديلات، ولا يعتبرها مكتملة.

حالة التقدم والإخفاء تخص المستخدم والشركة. الإغلاق لا يكمل الإعداد، والإخفاء يمنع الفتح التلقائي فقط. يظل زر فتح الدليل موجودًا في القائمة وإعدادات الشركة. تُحول حالات التقدم القديمة إلى الصفحة المجمعة المناسبة دون مسحها أو إعادة تهيئة الشركة. الجلسات القديمة ما زالت مدعومة عبر الواجهات السابقة.

## الواجهات والصلاحيات
- GET `/api/v1/guidance/setup/compact`: الصفحات الأربع والبيانات المسموحة وبصمة التعديل والجاهزية.
- PUT `/api/v1/guidance/setup/compact/{step}`: revision وdata وdefer؛ المفاتيح basics/preferences/store_setup/summary.
- PUT `/api/v1/guidance/setup/options/{section}`: تعديل مستقل دون تغيير تقدم الدليل؛ بيانات إضافية للشركة، هوية البائع والضريبة، الفواتير، العميل النقدي وأماكن العمل.
- `/api/v1/guidance/setup/resources/{resource}`: قوائم وإضافة وتعديل عبر متحكمات النطاق القائمة، خلف تحقق إضافي من صلاحية العملية وعضوية الشركة وملكية السجل. لا حذف من النوافذ الجديدة.
- PATCH `/api/v1/guidance/setup/preferences`: اختيار الإخفاء، دون استبدال بيانات النسخة المختصرة باستجابة الواجهة القديمة.

يحترم المسار صلاحيات الشركات والوصول الحالي للموارد. الحقول العامة المشتركة لا يعدلها بائع، وبيانات الصرف المقترحة تظل منفصلة ومشفرة عن الجهة المعتمدة. لا تُنشأ أرصدة أو معاملات وهمية، ولا يفتح الدليل البيع أو ينشر المنتجات أو يشترك بخدمة مدفوعة.

## الخريطة المجانية
تستمر Leaflet وOpenStreetMap دون مفتاح. عند توفير مفتاح Geoapify المجاني يبدأ البحث العربي داخل مصر من الخادم. متغير `GEOAPIFY_API_KEY` للخادم فقط؛ مفتاح منفصل `GEOAPIFY_MAP_KEY` اختياري للخرائط في المتصفح، ويجب تقييده بنطاقات المنصة لدى المزود. لا تحفظ المفاتيح في Git أو المحادثة.

الإعداد الافتراضي `MAP_SEARCH_DAILY_LIMIT=500` لطلبات البحث الخارجية، مع تخزين النتائج يومًا وتحديد المعدل وقفل عداد الحصة. هذا حد تطبيق للبحث، وليس ضمانًا لحصة المزود الكلية؛ تحميل خرائط Geoapify بالمفتاح المتصفحي يستهلك رصيدًا أيضًا ويُراقب من لوحة المزود. لا ترقية أو تحصيل تلقائي من التطبيق. حدود Geoapify المجانية قابلة للتغير؛ راجع https://www.geoapify.com/pricing/ قبل التفعيل.

GET `/api/v1/store/public/map-config` يعيد توفر البحث وإعدادات الخرائط العامة فقط. GET `/api/v1/store/public/map-search?q=...` يعيد حتى خمس نتائج بعنوان ونقطة، دون المفتاح الخاص أو استجابة المزود الخام. البحث بطلب واضح، وليس مع كل حرف. عند تعطل المزود أو بلوغ الحد تظهر رسالة محلية وتستمر الخريطة وتحديد الموقع والإدخال اليدوي؛ لا ينتقل المستخدم إلى صفحة تعطل النظام.

اختيار نتيجة أو موقع الجهاز لا يغير العنوان النصي ولا يؤكد النقطة تلقائيًا. يمكن تحريك العلامة وتأكيد المكان صراحةً؛ الإحداثيات اليدوية داخل تفاصيل إضافية. فحص التغطية الفعلية في الشرقية والصالحية يتطلب مفتاح حساب مجاني؛ الاختبارات المحاكية لا تثبت جودة تغطية المزود.

## التحقق والنشر
اختبارات الحفظ والحقول المستبعدة والجهوزية وعزل الشركات والصلاحيات والتقدم القديم وحدود البحث وعدم كشف المفتاح. اختبارات المتصفح تشمل النوافذ الإضافية وحفظ المسودة والتخطي وفشل البحث ورفض إذن الموقع. العروض المستهدفة 360 و390 و768 و959 و960 و1440، مع لوحة المفاتيح وعدم التمرير الأفقي. لا يحتاج التحديث إلى migration جديدة، ولا يغير إعدادات الشركات بمجرد النشر. النشر عبر GitHub Actions، والتحقق الحي بالقراءة فقط.
