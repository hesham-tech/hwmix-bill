# نشر الواجهة التجريبية

## النطاق

- الواجهة: https://staging.hwnix.com
- API: https://staging-api.hwnix.com/api/v1
- المستودع: hesham-tech/hwmix-bill، فرع النشر: staging.
- Workflow: .github/workflows/deploy-frontend-staging.yml.
- لا تعديل لفرع main أو مسار نشر الإنتاج أو بيئة الاختبار القديمة restructure-v2.

## النشر التلقائي

كل push إلى staging يشغل تثبيت التبعيات من package-lock، واختبارات الوحدة والبناء ثم النشر. يتوقف النشر إذا لم يتضمن آخر main وقت الفحص؛ ادمج main وحل التعارضات واختبرها أولًا. لا يوجد دمج تلقائي أو ضمان لمنع التعارض السلوكي؛ انقل التحسينات للإنتاج مستقبلًا بمراجعات مستقلة.

يضبط البناء VITE_API_BASE_URL وVITE_API_URL إلى API التجريبي، وVITE_APP_ENV إلى staging. تُعدل تحويلات معاينات الروابط في .htaccess داخل الحزمة التجريبية فقط. يفحص prepare-staging.mjs الناتج لمنع عناوين API الإنتاج والاختبار القديم، ويضيف منع الفهرسة ومرجع الإصدار. لا أسرار في متغيرات VITE أو ملفات البناء.

## الخادم وGitHub

- GitHub Environment: staging، يسمح بفرع staging فقط.
- Variables: STAGING_SSH_HOST وSTAGING_SSH_USER وSTAGING_SSH_PORT.
- Secrets: STAGING_SSH_PRIVATE_KEY لمفتاح جديد، وSTAGING_SSH_KNOWN_HOSTS لهوية مضيف موثوقة. لا تعاد كتابة المفاتيح أو نقلها للمستودع.
- يرفع dist فقط إلى /home/u715355537/apps/hwnix-frontend-staging/incoming، ثم يستخرج إلى releases/COMMIT ويبدل رابط current.
- جذر النطاق /home/u715355537/domains/hwnix.com/public_html/staging يشير إلى current. قبل أول تفعيل تُحفظ صفحة Hostinger في initial-placeholder، ولا تُستبدل ملفات غير معروفة.
- فشل التحقق من مرجع الإصدار أو استجابة الموقع يعيد رابط إصدار الواجهة السابق، أو الصفحة الافتراضية في أول نشر. لا تنفيذ PHP أو migrations أو seeders أو تغييرات قاعدة بيانات ضمن هذا النشر.
- تبقى الأصول ذات الأسماء المجزأة من الإصدار السابق متاحة لدعم التبويبات المفتوحة. تتراكم الإصدارات والأصول، ويحتاج تنظيفها لاحقًا سياسة احتفاظ منفصلة.
- حساب Unix وموارد الاستضافة مشتركة مع المواقع الأخرى؛ هذا فصل مسارات وليس عزلاً نظاميًا. لا اختبارات حمل في هذه المرحلة.

## التحقق المطلوب

نجاح الاختبارات والبناء وActions، وتطابق staging-revision.txt مع Commit، وتحميل صفحة التطبيق وملفات JavaScript وCSS ومسارات SPA عبر HTTPS، والتحقق من طلبات المتصفح إلى staging-api فقط. عدم عرض منتجات أو خطط في قاعدة اختبار جديدة ليس دليلًا وحده على فشل الربط؛ لا تستورد بيانات الإنتاج لتعبئتها تلقائيًا.

## حالة المرحلة

الإعداد قيد الفحص والنشر. يُسجل المرجع والتشغيل والنتيجة بعد التحقق الفعلي؛ ثم يتوقف التنفيذ قبل أي مرحلة تحسين أخرى.
