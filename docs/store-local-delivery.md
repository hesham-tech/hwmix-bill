# التوصيل المحلي وإحداثيات المخازن
تاريخ التحديث: 12 نوفمبر 2026.

## القرار المعتمد
مصدر نقطة الاستلام الافتراضية هو المخزن الفعلي المحدد لتنفيذ منتجات البائع، مع عنوانه النصي. تغيير نقطة استلام الطلب فقط قبل الإرسال يتطلب صلاحية مستقلة وسببًا وتأكيدًا، ويحفظ الأصل والفاعل والتوقيت. لا يغير المخزون أو المخزن أو طريقة التوصيل أو السعر؛ تغيير الطريقة أو السعر يحتاج موافقة جديدة من العميل، ولا ينفذه تعديل الاستلام.

## الإعداد
1. المخازن: احفظ العنوان وإحداثيات حقيقية مؤكدة.
2. متجر شركتي: فعّل التوصيل المحلي وحدد النطاق والرسم وحد المجانية الاختياري. الإحداثيات هنا للعرض من المخزن.
3. فوض صلاحيات الإعداد والإدارة والتحصيل وتعديل الاستلام كلًا بصورة مستقلة عند الحاجة.
4. داخل النطاق يستخدم توصيل البائع تلقائيًا؛ خارجه ناقل البائع ثم ناقل الإدارة. عند غياب ناقل مسعّر متاح لهذا العنوان وطريقة الدفع، يعود الطلب لتوصيل البائع مهما كانت المسافة وبالرسم وحد المجانية المحددين له. يتطلب ذلك تفعيل إعداد التوصيل الذاتي وتجهيزه؛ لا تفترض رسوم أو نقاط جديدة تلقائيًا.

الخيار معطل افتراضيًا، ولا تفتح إضافته الشراء. لا تنشأ إحداثيات من المدينة أو من عنوان غير محدد على الخريطة. يتطلب الشراء نقطة عميل مؤكدة إذا شملت السلة بائعًا فعّل الميزة.

## قواعد المال والتشغيل
الرسم يقبل الصفر، والمجانية تقارن بقيمة منتجات جزء البائع بعد الخصم وشاملة ضريبتها. الرسوم للبائع والعمولة على المنتجات وفق السياسة الحالية. لا حساب ناقل وهميًا ولا مديونية أو قيود ناقل، حتى صفرية، ولا ربط تلقائي بخزائن ERP. التحصيل الذاتي مؤكد بمرجع وصلاحية منفصلة ومنع تكرار القيد. تدعم حالات التجهيز والخروج والتسليم والرجوع والمرتجع.

يحفظ عرض السعر والطلب طريقة التوصيل والنقاط والمسافة وإصدار الإعدادات. تغيير البيانات المؤثرة يبطل العرض. لا تكشف نقطة المخزن في API العميل. الإشعارات مقيدة بجزء البائع وعضوية الموظف النشطة وصلاحياته المعاد فحصها عند الإرسال.

## الخرائط والاستضافة
Leaflet 1.9.4 وOpenStreetMap افتراضيًا، دون خدمة طرق أو تحويل عناوين. VITE_STORE_MAP_TILE_URL وVITE_STORE_MAP_ATTRIBUTION يتيحان تغيير مزود المربعات والإسناد أثناء البناء. تحترم سياسة https://operations.osmfoundation.org/policies/tiles/؛ لا تحميل جماعي أو مسبق، والإسناد ظاهر والتخزين المؤقت للمتصفح محفوظ. الخدمة العامة لا تضمن التوافر؛ يتاح الإدخال اليدوي ورفض GPS.

## البيانات والإطلاق
Migration 2026_11_12_000018 تضيف إعدادات وإحداثيات وصلاحيات ونوع الشحنة. الطلبات السابقة تظل carrier، والناقل nullable للتوصيل الذاتي. لا تتراجع عن المخطط عشوائيًا بعد وجود طلبات ذاتية؛ يحتفظ down بنوع الشحنة وقابلية غياب الناقل لحماية تفسير السجل. يلزم نسخ احتياطي قبل النشر.

## التحقق
اختبارات مسافة الحد والإحداثيات والرسوم والتسعير المتغير والصلاحيات وعزل الشركات والإشعارات والتحصيل والمخزون والقيود والطلب المختلط والدفع الإلكتروني دون ناقل؛ اختبارات متصفح للإعداد والعناوين القديمة ورفض GPS وتعطل الخريطة وتعديل الاستلام ودورة التوصيل. بيانات الاختبار معزولة؛ لا تنشأ طلبات حقيقية أو تفعّل شركات تلقائيًا.

## الحدود المتبقية
يلزم إدخال إحداثيات المخزن الحقيقية والنطاق والرسوم ثم تجربة تشغيل فعلية قبل فتح الشراء. التعاقد مع بوابة دفع وناقل خارجي خارج هذه الإضافة. تنبيها تدقيق npm الإنتاجيان السابقان في مسار إزالة خلفية الصور باقـيان؛ لا تخص Leaflet، وتغيير ذلك المسار يحتاج تحققًا مستقلًا. رسوم أو طريقة مختلفة بعد التأكيد لا تنفذ آليًا عبر تعديل الاستلام.

## إتاحة طرق الدفع
الدفع عند الاستلام متاح دائمًا للطلبات الجديدة. البطاقة متاحة بجانبه عند تفعيل الدفع الإلكتروني ووجود بوابة نشطة ومكتملة ومناسبة لبيئة التشغيل. غياب البوابة أو عدم جاهزيتها يخفي البطاقة ويمنع طلبها عبر API، ولا يعطل فتح المتجر. لا يتم تفعيل حساب دفع تجريبي على الإنتاج تلقائيًا.
