# تكامل الخرائط والبحث عن العناوين
من القائمة: المتجر الإلكتروني ← الخرائط والبحث عن العناوين. الإعداد عام للمنصة، وليس للشركة.
المسؤول العام أو مفوض نشط داخل شركة المنصة بصلاحية store.maps.manage فقط يستطيع قراءته وتعديله واختباره؛ مدير البائع لا يحصل عليها تلقائيًا.
أنشئ حساب Geoapify بالخطة Free، وانسخ مفتاح API من مشروعك إلى حقل مفتاح البحث، ثم احفظ واختبر. المفتاح محفوظ مشفرًا ولا يعود في استجابات الإدارة أو الجمهور. الحقل الفارغ يحتفظ به؛ الحذف صريح. مفتاح الخرائط منفصل واختياري ويظهر للمتصفح ويجب تقييده بنطاقات الموقع.
لا تقيد مفتاح البحث بدومين المتصفح؛ الطلب من الخادم. يمكن تقييده بعنوان خروجه بعد التأكد منه. حد البحث محلي من 0 إلى3000 طلب يوميًا (افتراضي500)، ولا يغني عن مراقبة رصيد المزود. اختبار الاتصال مستقل ويستهلك طلبًا محدودًا بثلاث محاولات في الدقيقة؛ لا يختبر مفتاح صور الخرائط. لا ترقيات مدفوعة من النظام.
GET/PATCH /api/v1/admin/store/maps وPOST /api/v1/admin/store/maps/test. يوجد revision لمنع الكتابة فوق تغيير أحدث. تظل قيم env القديمة احتياطية فقط إلى أول حفظ من اللوحة؛ بعده يصبح سجل map_integration المستقل المصدر المعتمد حتى عند التعطيل أو الحذف.
لا فتح للشراء ولا تغيير لبيانات الشركات. عند غياب المفتاح أو التعطيل تستمر الخريطة الحالية والإحداثيات اليدوية.
